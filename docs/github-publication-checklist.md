# GitHub Publication Checklist

Use this checklist before pushing YTIS to a private or public GitHub repository.

## Required before private push

- README uses first person and explains the AIDE/YTIS purpose.
- Safety boundaries exist.
- Roadmap exists.
- Sample workflow exists.
- Generated runtime data is ignored or untracked.
- No secrets or credentials are committed.
- No private customer data is committed.
- Python compile check passes.
- Publication validation passes.
- Git status is clean after commit.

## Required before public release

- Use only public-safe sample data.
- Remove local machine paths.
- Add screenshots that do not expose private information.
- Add install/demo notes that work on a clean machine.
- Review license and third-party dependencies.
- Avoid unsupported AI claims.
