# YTIS Sample Workflow

This sample uses public-safe source material and a human-in-the-loop ChatGPT workflow.

## Scenario

I want to study a public expert source and extract practical lessons for career development, business research or technical learning.

## Workflow

1. Create or select a source project.
2. Build a source pack from public-safe material.
3. Inspect source readiness and transcript/document counts.
4. Start a guided mission.
5. Export the step handoff pack and prompt.
6. Upload the pack to ChatGPT and request the analysis.
7. Review the answer.
8. Save the answer back into YTIS.
9. Advance to the next step.
10. Generate a final action pack.
11. Convert important findings into knowledge cards.

## Example outputs

- source credibility summary;
- structured topic map;
- risks and limitations;
- practical workflows;
- learning plan;
- opportunity analysis;
- evidence cards;
- final action report.

## Review rule

No AI output should be treated as final without human review.
